# Security

Do not publish pairing payloads, one-use codes, certificates, database files, logs, memory diagnostics, or diagnostic exports in an issue.

To report a vulnerability, use GitHub's private security-advisory feature for this repository. If that option is unavailable, open an issue containing no secrets or private data and ask for a private contact channel.

The Bridge is intended only for a trusted private LAN. Do not forward its port, expose it through a public tunnel, or weaken the firewall scope beyond Private networks and `LocalSubnet`.
